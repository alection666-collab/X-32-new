X32 TOUCH PRO v0.1 — интерактивный визуальный прототип

Запуск:
1. Распакуйте архив.
2. Откройте index.html в Chrome или Edge.
3. Для проверки на iPad разместите файл на веб-хостинге (например, GitHub Pages) или откройте через локальный сервер в одной сети.

Сейчас реализованы:
- адаптивный интерфейс микшера;
- 16 сенсорных фейдеров на экране (на широком экране сетка до 16);
- MUTE / SOLO в демонстрационном режиме;
- переключение банков;
- Tap Tempo с расчётом BPM и миллисекунд;
- базовое создание и сохранение Custom Layers в localStorage;
- панели Channel, Bus/Sends, FX и Settings.

Важно:
Это пока UI-прототип. Он НЕ подключается к X32, не отправляет OSC-команды и не отображает реальные уровни сигнала. Для реального управления следующим этапом добавим OSC-мост/сетевой модуль и синхронизацию состояния.
